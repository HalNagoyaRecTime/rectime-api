# 通知詳細・イベント説明の保存契約

本文の形式は文字列ひとつです。Markdown専用のDB列や形式判定は追加しません。

通知のcontent.detail.bodyとイベントのrule_textは、先頭末尾の改行、字下げ、行末空白を含め、入力文字列を加工せず保存・返却します。通知タイトルとPush本文のtrimは従来どおりです。通知本文の空白だけの入力は拒否し、イベントのnull・空文字・最大1000文字は従来どおりです。

表示側では単独改行はsoft break、行末空白2個以上またはバックスラッシュ＋改行はhard break、空行は段落として扱います。普通の文章も同じMarkdownで表示できます。

変更は今後の書き込みに適用されます。すでに削られた空白は復元しません。管理画面とモバイルの対応をマージする前にAPIを反映してください。
